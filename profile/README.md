# Polysync

Polysync is a multi-cloud orchestration platform for data and AI workloads. It connects the platforms a
team already runs, so they share one schedule, one cross-platform dependency graph and one run history.

- **Website:** https://www.polysync.com.au
- **Documentation:** https://www.polysync.com.au/documentation
- **Microsoft Marketplace:** https://marketplace.microsoft.com/en-us/product/saas/polysyncdatasolutionsptyltd1749542123409.polysync-orchestration-platform-live

## What it does

- Orchestrates more than 20 services across Microsoft Azure, Google Cloud and Amazon Web Services,
  including Azure Data Factory, Azure Databricks, Microsoft Fabric, Power BI, Azure OpenAI, AWS Glue,
  AWS Step Functions and Google Cloud Composer.
- Discovers jobs from the connected platforms with their parameters, so a task is configuration rather
  than code.
- Links tasks on different platforms with On Success, On Failure or On Completion dependency triggers,
  resolved across the whole graph with cycle detection.
- Schedules in any time zone, with several independent schedules per task.
- Caps concurrency or start rate with contention profiles, per platform or across the estate.
- Keeps credentials in Azure Key Vault, AWS Secrets Manager, Google Cloud Secret Manager or HashiCorp
  Vault.

Every run, retry and outcome lands in one execution history, with an AI monitoring agent that can explain
a failure and, only where authority is granted, retry what is safe.
